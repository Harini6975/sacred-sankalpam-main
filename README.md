# Pooja & Priest Booking Platform

A responsive frontend web application built with **HTML5**, **CSS3**, and **Vanilla JavaScript** supporting **English** and **Tamil** languages, **Light** and **Dark** themes, public pooja and priest pages, authentication pages, and **Devotee**, **Priest**, and **Admin** dashboards.

## Important Frontend-Only Note
- This initial build uses plain HTML, CSS, and Vanilla JavaScript without backend servers, databases, or real payment gateways.
- Browser storage (`localStorage` / `sessionStorage`) is used only for frontend prototype state and preferences—not for secure authentication, role security, or production multi-user data.
